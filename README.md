# 🍅 Tomato Leaf - Disease Detection App

A complete Flutter application with AI-powered tomato leaf disease detection using a pre-trained ResNet50 model, plus an intelligent AI assistant with voice capabilities.

## ✨ Features

- 📸 Camera Capture - Take photos of tomato leaves
- 🖼️ Image Import - Upload existing photos from gallery
- 🔬 AI Detection - Accurate disease identification using ResNet50
- 💊 Treatment Info - Detailed recommendations for each disease
- 📊 Confidence Scores - View prediction confidence percentages
- 🤖 **NEW: AI Assistant** - Chat with AI about tomato diseases and care
- 🎤 **NEW: Voice Input** - Ask questions using speech-to-text
- 🔊 **NEW: Voice Output** - Listen to AI responses with text-to-speech
- 🌐 Cross-Platform - Android, iOS, Web, Windows, Linux, macOS

## 🎯 Detected Diseases (10 Classes)

Healthy, Bacterial Spot, Early Blight, Late Blight, Leaf Mold, Septoria Leaf Spot, Spider Mites, Target Spot, Tomato Mosaic Virus, Yellow Leaf Curl Virus
